Text-to-SVG Diagrams for Excel

Mermaid 記法で書いたフローチャート・シーケンス図・ER 図などを、そのまま Excel のシートに画像として挿入できる Office アドインです。処理はすべてローカルで完結します。 An Office Add-in that turns Mermaid text into flowcharts, sequence diagrams, ER diagrams and more, and inserts them into your Excel sheet as images. Everything runs locally.

主な機能Features

テキストで書いて、プレビューして、ワンクリックで挿入。 Write text, preview it, insert it with one click.

リアルタイムプレビューLive preview

入力するそばからタスクペイン内でダイアグラムを描画します。 The diagram renders in the task pane as you type.

ワンクリックで挿入One-click insert

プレビューした画像をアクティブセルの位置に挿入します。 Insert the previewed image at the active cell.

挿入後も再編集Re-edit later

Mermaid コードは図の代替テキストに保存。[Sheet diagram] から選んで編集・差し替えできます。 The code is kept in the image's alt text. Pick it from [Sheet diagram] to edit and replace it.

PNG / JPEG / SVGPNG / JPEG / SVG

形式を選んで挿入、またはファイルとしてダウンロードできます。 Choose a format to insert, or download the image as a file.

あらゆる図に対応Every diagram type

フローチャート、シーケンス図、クラス図、ER 図、ガントチャートなど Mermaid の全記法が使えます。 Flowcharts, sequence, class, ER, Gantt and every other Mermaid diagram.

データは外に出ないStays on your PC

描画も挿入もタスクペイン内で完結。入力内容は送信されません。 Rendering and inserting happen in the task pane. Nothing you type is sent anywhere.

導入方法Install

マニフェストファイル（manifest.xml）を Excel に登録するだけで使えます。お使いの環境に合わせて方法を選んでください。 Register the manifest file (manifest.xml) with Excel. Pick the method that fits your setup.

方法 1・かんたんMethod 1 · Quick

マニフェストをアップロードUpload the manifest

Excel for the web / Microsoft 365 版 Excel Excel for the web / Excel for Microsoft 365

  1. マニフェストをダウンロードします。 Download the manifest.
    manifest.xml をダウンロードDownload manifest.xml
  2. Excel でブックを開き、[挿入] → [アドイン] → [個人用アドイン] を開きます。 In Excel, open a workbook and go to Insert → Add-ins → My Add-ins.
    • 表示がない場合は [ホーム] → [アドイン] → [その他のアドイン] から開きます。 If it's not there, use Home → Add-ins → More Add-ins.
  3. [アドインをアップロード]（または [マイ アドインのアップロード]）を選び、ダウンロードした manifest.xml を指定します。 Choose Upload My Add-in and select the downloaded manifest.xml.

アップロードしたアドインは、そのアカウントやブラウザーの環境によっては後で一覧から消えることがあります。その場合は同じ手順で再度アップロードしてください。 Depending on your account or browser, an uploaded add-in may disappear from the list later. If so, upload it again the same way.

方法 2・常設Method 2 · Persistent

共有フォルダーカタログShared folder catalog

Windows 版 Excel（デスクトップ） Excel on Windows (desktop)

  1. 任意のフォルダー（例: C:\OfficeAddIns）を作り、manifest.xml を保存します。 Create a folder (e.g. C:\OfficeAddIns) and save manifest.xml into it.
  2. そのフォルダーを共有します。エクスプローラーでフォルダーを右クリック → [プロパティ] → [共有] → [共有]。表示されたネットワークパス（例: \\PC名\OfficeAddIns）を控えます。 Share the folder: right-click it in File Explorer → Properties → Sharing → Share. Note the network path shown (e.g. \\PCNAME\OfficeAddIns).
  3. Excel で [ファイル] → [オプション] → [トラスト センター] → [トラスト センターの設定] → [信頼できるアドイン カタログ] を開きます。 In Excel, open File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs.
  4. [カタログの URL] に共有パスを入力して [カタログの追加]。[メニューに表示する] にチェックを入れて OK し、Excel を再起動します。 Enter the share path in Catalog Url, click Add catalog, check Show in Menu, click OK and restart Excel.
  5. [ホーム] → [アドイン] → [その他のアドイン] → [共有フォルダー] から Text-to-SVG Diagrams for Excel を選んで [追加]。 Go to Home → Add-ins → More Add-ins → Shared Folder, select Text-to-SVG Diagrams for Excel and click Add.

登録できたらOnce it's registered

[ホーム] タブの右端に [Open Mermaid] ボタンが追加されます。クリックするとタスクペインが開きます。 An Open Mermaid button appears at the right end of the Home tab. Click it to open the task pane.

使い方How to use

記法の詳細は Mermaid の公式ドキュメント を参照してください。 See the Mermaid documentation for the syntax.

  1. 図を挿入したいセルを選択し、[Open Mermaid] でタスクペインを開きます。 Select the cell where the diagram should go and click Open Mermaid.
  2. 入力欄に Mermaid コードを書くと、下にプレビューが表示されます。 Type Mermaid code in the editor; the preview appears below it.
  3. 形式（PNG / JPEG / SVG）を選んで [Insert to Excel]。ファイルとして保存するときは [Download]。 Pick a format (PNG / JPEG / SVG) and click Insert to Excel, or Download to save it as a file.
  4. あとで直すときは [Sheet diagram] から図を選ぶとコードが読み込まれ、編集して差し替えられます。 To change it later, pick the diagram in Sheet diagram; its code loads back in so you can edit and replace it.

プライバシーPrivacy

Text-to-SVG Diagrams for Excel は個人情報やデータを一切収集しません。 Text-to-SVG Diagrams for Excel does not collect any personal information or data.

  • 入力した Mermaid コードの処理とダイアグラムの描画は、タスクペイン内だけで行います。 Your Mermaid code is processed and rendered only inside the task pane.
  • シートへの画像挿入は Office JavaScript API を通じてローカルで行います。 Images are inserted locally through the Office JavaScript API.
  • 通信はアドイン本体（HTML / JavaScript）をこのサイトから読み込むときだけで、ユーザーのデータは含みません。 The only network traffic is loading the add-in itself (HTML / JavaScript) from this site, and it contains none of your data.
  • Cookie、ローカルストレージ、トラッキング技術は使いません。 No cookies, local storage or tracking technologies are used.
