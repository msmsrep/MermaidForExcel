# Mermaid for Excel 今後の予定

未実装の機能追加候補をまとめる。現行の仕様は [specification.md](./specification.md) を参照。

優先して検討する順は **1 → 3 → 5**。

## Excel 連携

### 1. セル範囲から Mermaid コードを生成

選択した表から Mermaid コードを生成してエディタに入れる。

- `親 | 子` の 2 列 → フローチャート
- `タスク | 開始日 | 終了日` → ガントチャート
- `項目 | 値` → 円グラフ

### 2. セル値の差し込み（プレースホルダ）

コード中の `{{Sheet1!B2}}` のような記述を、描画時にセルの値へ置き換える。

### 3. シート上の図形選択で自動読み込み

`onSelectionChanged` で選択中の図形を検出し、Mermaid 図ならエディタに読み込む。現状は [Sheet diagram] ドロップダウンからの選択のみ。

### 4. 一括再描画

シート（またはブック）内の Mermaid 図を、代替テキストに保存したコードからまとめて描き直す。テーマ変更・mermaid 更新後や、2 と組み合わせたデータ更新時に使う。

## 使い勝手

### 5. テーマ・見た目の設定

テーマ（default / dark / forest / neutral）、背景色、フォントを選べるようにする。現状は `theme: "default"` 固定。

### 6. 出力サイズ・解像度の指定

倍率または幅（pt）を指定する。差し替え時に元の図形サイズを維持するオプションも用意する。

### 7. テンプレート挿入

図の種類ごとのひな形をドロップダウンから挿入する。

### 8. エラー位置の強調

構文エラーから行番号を取り出し、入力欄の該当行を強調する。

## 小改善

- 図に任意の名前を付ける（ドロップダウンの表示名）
- ブック全体の図一覧（現状はアクティブシートのみ）
- コードのクリップボードコピー、`.mmd` の保存・読み込み
- 入力欄のシンタックスハイライト

## 検討事項

- 設定（5・6）の保存先。プライバシーポリシーで「ローカルストレージ不使用」と明記しているため、`Office.context.document.settings`（ブック内に保存）を使うか、ポリシーを改訂するかを決める。
